Bienvenue dans MailDesk

Retrouvez un espace existant ou configurez ce PC comme une nouvelle installation.

Espace existant

Se connecter et restaurer MailDesk

Connectez-vous avec votre compte Supabase. MailDesk restaurera la base locale depuis votre espace synchronisé : messages, dossiers, contacts, règles, modèles, calendrier, blocages et signature.

Connexion utilisateur sécurisée Aucune clé service_role n’est nécessaire. Le mot de passe sert uniquement à ouvrir la session Supabase et n’est jamais enregistré par MailDesk.
Restauration terminée

Finaliser ce PC

Vos données MailDesk sont revenues depuis Supabase. Les secrets restent volontairement locaux : renseignez la clé Resend de ce PC pour terminer.

✓
La clé Resend reste chiffrée localement avec Electron safeStorage. Elle n’est pas écrite dans les tables Supabase synchronisées.
Nouvelle installation

Configurer MailDesk manuellement

Utilisez ce mode si vous ne restaurez pas un espace existant. Vous pourrez connecter Supabase plus tard depuis les paramètres.

Configuration locale Les secrets sont chiffrés avec Electron safeStorage. Vous pourrez ensuite activer la synchronisation Supabase depuis Paramètres → Supabase.
